# PikoSite

Поиск информации по домену через терминал: `Piko --example.com`

Файлы: index.html, style.css, app.js, resources.js (база из 50+ ресурсов).

Запуск: откройте `index.html` в браузере (или выложите папку на GitHub Pages / любой статический хостинг).
Сборка не нужна. Все запросы идут из браузера к открытым API (DNS-over-HTTPS, RDAP, ipwho.is, crt.sh, Wayback Machine).

Команды терминала: `Piko --домен`, `export txt`, `export json`, `history`, `help`, `clear`.
